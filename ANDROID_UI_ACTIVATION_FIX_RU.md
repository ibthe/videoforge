# Исправления Android: активация и компактный интерфейс

- Окно лицензии перестроено под узкий экран: поля и действия расположены вертикально, содержимое прокручивается при открытой клавиатуре.
- Кнопка активации теперь показывает состояние выполнения; ошибки валидации, сети, сервера и исключения отображаются прямо в диалоге.
- Если лицензия ещё инициализируется, приложение сообщает об этом вместо молчаливого закрытия окна.
- Проверка времени остаётся отдельным действием и не занимает место рядом с кнопкой активации.
- На Android главный блок сделан короче, описания профилей ограничены двумя строками, а дополнительные инструменты свернуты в отдельную секцию.
- Блок сохранения показывает галерею и альбом VideoForge вместо внутреннего пути приложения.

Проверено: целостность ZIP, Python-скрипт подготовки платформ и баланс скобок в изменённом Dart-файле. Полная сборка Flutter в этой среде не запускалась; её необходимо проверить через GitHub Actions.
