# VideoForge — проект приложения для 4 платформ

VideoForge — простой видеоконвертер с одним общим интерфейсом для Windows, macOS, Android и iPhone. Пользователь выбирает одно или несколько видео и нажимает **«Кодировать»**. Приложение само создаёт папку результата и кодирует файлы в MP4 (H.264 + AAC).

## Что уже реализовано в исходниках

- Выбор нескольких файлов: MP4, MOV, MKV, M4V, AVI, WEBM; на macOS/Windows также доступно перетаскивание видео в окно.
- Кодирование через встроенный FFmpegKit; отдельно устанавливать FFmpeg и менять `PATH` не требуется.
- Профили экспорта: высокое качество, сбалансированный, компактный размер и YouTube 1080p.
- Живой прогресс кодирования, скорость, примерное оставшееся время и кнопка отмены обработки.
- Сравнение размера оригинала с готовым файлом; исходники не удаляются.
- Сохраняются доступные метаданные и главы; MP4-кодирование использует H.264/AAC, `yuv420p` и `+faststart`.
- Существующие MP4 не перезаписываются — при совпадении имени добавляется суффикс `_2`, `_3` и т. д.
- Готовый файл можно экспортировать через системное меню «Поделиться».
- Для Windows/macOS есть кнопка открытия папки результата; в CI подпись macOS проверяется до упаковки установщиков.

## Куда сохраняются результаты

- **Windows:** `%USERPROFILE%\Videos\Processed_New`
- **macOS:** `~/Movies/Processed_New`
- **Android:** папка `Processed_New` в документах приложения; используйте кнопку «Поделиться», чтобы сохранить видео в галерею, «Файлы» или другое место.
- **iPhone:** папка `Processed_New` в документах приложения. Включён доступ к документам приложения через Files; готовое видео также можно экспортировать через «Поделиться».

На macOS приложение получает entitlement доступа к папке Movies. Если ОС перенаправляет системные папки или запрещает создать папку, предусмотрен резервный путь в Documents приложения.

## Требования разработчика

- Flutter **3.38.1 или новее** (Dart 3.10+).
- Python 3 для генерации файлов платформ.
- Windows build: Windows 10/11 x64 и Visual Studio 2022 с workload **Desktop development with C++**.
- macOS/iPhone build: macOS, Xcode и Command Line Tools. Сборка iPhone для распространения требует настроенной подписи Apple.
- Android build: Android Studio/SDK; Android min SDK устанавливается в 24.

> Сборку нужно выполнять на соответствующей ОС: Windows-сборку — на Windows, macOS/iPhone — на Mac, Android APK/AAB можно собирать на Windows, macOS или Linux при установленном Android SDK. В этой архивной среде нет Flutter и Xcode, поэтому архив содержит исходники и сборочные сценарии, а не уже собранные подписанные установщики.

## Автоматическая сборка на GitHub

В проект добавлен workflow `.github/workflows/build.yml`. После загрузки исходников в GitHub он собирает Windows, macOS, Android и проверочную iOS-версию на облачных runners. Готовые файлы доступны во вкладке **Actions** как workflow artifacts в течение 14 дней. Кэш Flutter отключён, чтобы не создавать дополнительный архив кэша при пост-очистке runner; сборки будут загружать инструменты и зависимости заново. Для macOS перед упаковкой проверяется наличие нужных entitlements в подписи приложения.

Пошаговая инструкция первого запуска на русском находится в [`GITHUB_SETUP_RU.md`](GITHUB_SETUP_RU.md). Учти: первая iOS-сборка unsigned и нужна для проверки компиляции; для установки на iPhone и публикации потребуется Apple signing. Для коммерческого распространения также предстоит настроить подпись установщиков и Android release signing.

## Быстрая подготовка платформ

1. Распакуйте проект.
2. Откройте терминал в папке `VideoForgeProject`.
3. Запустите:

```bash
python3 scripts/prepare_platforms.py
flutter pub get
```

В Windows можно использовать `python scripts\prepare_platforms.py` в PowerShell. Скрипт создаёт отсутствующие каталоги платформ средствами Flutter и применяет минимальные настройки версий ОС и доступов к папкам.

## Сборка

### Windows

В PowerShell:

```powershell
.\scripts\build_windows.ps1
```

Результат: `dist\VideoForge-Windows-Portable.zip`. Это готовая портативная папка с exe и библиотеками.

Чтобы получить обычный `VideoForge-Windows-Setup.exe`, установите Inno Setup и повторно запустите скрипт. Сценарий установщика находится в `installer/VideoForge.iss`. Для продажи широкому кругу пользователей рекомендуется подписать установщик Authenticode-сертификатом.

### macOS

```bash
bash scripts/build_macos.sh
```

Результат: `dist/VideoForge-macOS.dmg`. Перед коммерческой раздачей подпишите приложение Developer ID и пройдите Apple notarization; неподписанное приложение может вызывать предупреждения Gatekeeper.

### Android

```bash
bash scripts/build_android.sh
```

Результаты:
- `dist/VideoForge-Android.apk` — ручная установка/тестирование.
- `dist/VideoForge-Android.aab` — загрузка в Google Play.

Для публикации в магазине нужно настроить собственный upload/release signing key и сохранить его резервную копию.

### iPhone (iOS)

Сборка выполняется на Mac:

```bash
bash scripts/build_ios.sh
```

Перед сборкой откройте `ios/Runner.xcworkspace` в Xcode, выберите **Runner → Signing & Capabilities**, назначьте Team и задайте уникальный Bundle Identifier. Затем запустите сценарий снова. Результат — `dist/VideoForge-iPhone.ipa`.

Для обычных покупателей iPhone установку организуют через **App Store** или **TestFlight** (для тестирования); пользователь не может установить произвольный `.ipa` так же свободно, как `.exe`.

## Проверка перед выпуском

Этот проект — функциональная первая версия, но его необходимо собрать и прогнать на реальных устройствах перед продажей. Рекомендуемый smoke-test:

1. Выбрать короткий MP4 с аудио и закодировать.
2. Выбрать MOV/MKV и проверить дорожки аудио/видео.
3. Попробовать видео без звука.
4. Повторить кодирование файла с тем же именем и убедиться, что предыдущий результат не перезаписан.
5. Проверить длинный ролик, свободное место, блокировку экрана и поведение приложения при сворачивании на телефоне.
6. Проверить экспорт через «Поделиться» на Android/iPhone.

## Замечания для коммерческого выпуска

- В этом прототипе подключён `ffmpeg_kit_flutter_new`, который включает GPL-компоненты, в том числе `libx264`. Архитектура и набор библиотек выбраны для демонстрации желаемого поведения; до продажи нужно отдельно решить лицензионные вопросы и сохранить необходимые notices/license files в поставке.
- Windows-пакет FFmpegKit ориентирован на x64; нативную Windows ARM-сборку этот проект пока не заявляет.
- Скорость кодирования и автономная работа в фоне на Android/iOS зависят от устройства и ограничений ОС. Эта версия выполняет кодирование, пока приложение открыто; управление фоновыми задачами и очередью после закрытия можно добавить отдельным этапом.
- До продажи стоит добавить собственные иконки, контакт поддержки, страницу конфиденциальности, диагностику свободного места и финальный тест на минимальных поддерживаемых версиях ОС.
