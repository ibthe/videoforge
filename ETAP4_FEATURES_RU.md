# VideoForge — расширение функций (этап 4)

Добавлены в текущий Flutter-проект:

- Анализ видео через FFprobe и просмотр технических свойств в JSON.
- Конструктор пользовательского H.264-профиля: CRF 0–35 и preset; настройки сохраняются.
- Приблизительная оценка размера для очереди (не гарантия размера файла).
- Проверка выходного файла через FFprobe после кодирования, если метаданные доступны.
- История успешно завершённых экспортов, доступная из сохранённой очереди.
- Менеджер публикаций: локальные поля названия, описания, тегов и заметок для каждого ролика.
- Техническое сравнение метаданных исходника и результата.
- Экспорт диагностического отчёта через системное меню «Поделиться».
- Логирование успешных операций и ошибок FFmpeg/FFprobe.
- Существующая логика создаёт отдельный выходной файл и не перезаписывает исходник.

Ограничения:

- Предварительная оценка размера является эвристикой. Реальный размер зависит от содержимого, разрешения, движения и аудио.
- Сравнение метаданных не является визуальным сравнением кадров и не доказывает отсутствие потерь. Для строгого контроля lossless можно отдельно добавить сравнение декодированных кадров.
- Менеджер публикаций хранит варианты и заметки локально; он не подключается автоматически к аналитике YouTube/TikTok/Instagram.
- Для мобильных платформ системная функция «Поделиться» используется для передачи диагностического отчёта.
- Flutter SDK не был доступен в среде подготовки, поэтому перед выпуском обязательно прогнать CI для Android, iOS, macOS и Windows.
