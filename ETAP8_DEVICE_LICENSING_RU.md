# Этап 8 — привязка лицензии к одной установке

Реализованы: серверная активация ваучера, привязка к email и случайному ID установки, 7-дневное окно активации с даты создания, 365-дневный срок лицензии с момента первой активации, атомарное резервирование `licenseId` в SQLite, повторный запрос с того же ID без повторной выдачи срока и отказ для другой установки. Сервер возвращает подписанный Ed25519 токен `VFL1`; приложение проверяет его встроенным открытым ключом сервера.

Секретные ключи намеренно не включены в этот проектный ZIP. Используйте отдельные архивы издателя и сервера.

См. `licensing_server/README_RU.md` и `ETAP7_LICENSE_RU.md` для развёртывания и выпуска.
