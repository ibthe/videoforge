# VideoForge — этап 6: сравнение профилей

## Что добавлено

- Кнопка «Сравнить профили» запускает последовательный тест выбранных профилей на одном исходном видео.
- Пользователь выбирает исходник и от одного до всех доступных профилей.
- Для каждого профиля создаётся отдельный фрагмент до 20 секунд с уникальным именем; исходник не изменяется.
- Каждый тест проверяется на существование, ненулевой размер и читаемость через FFprobe.
- В итоговом отчёте показываются профиль, размер результата, время обработки и путь к файлу; ошибки перечисляются отдельно.
- В диагностический журнал добавляются события успешных и неуспешных тестов.

## Ограничения

Это сравнение размера и скорости, а не автоматическая оценка визуального качества. Размер тестового фрагмента не гарантирует размер полного видео. Режим FFV1 может создавать значительно большие файлы. Для профиля «Мой профиль» используется сохранённая настройка CRF/preset приложения.

## Проверка

Архив проверен на целостность. В среде подготовки не установлен Flutter SDK, поэтому перед выпуском требуется прогнать GitHub Actions для Android, iOS, macOS и Windows и вручную проверить сравнение на коротком видео.
